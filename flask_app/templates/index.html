About

This application helps you optimize glass manufacturing production planning under demand uncertainty. Upload your Excel file to get started.

Features
  • Load and explore your data
  • Edit values interactively
  • Run baseline optimization
  • Perform Monte Carlo simulation
  • Tune safety stock parameters
Required File Format

Your Excel file must contain two sheets:

  • Demandes - Demand data with 'Modèles' as index
  • DonneesSup - Additional parameters with 'Modèles' as index

Example structure: 12 weeks of demand data, 6 glass models
